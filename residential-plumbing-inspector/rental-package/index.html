Exam Details

The ICC P1 Residential Plumbing Inspector examination is a certification exam for individuals seeking to demonstrate knowledge of residential plumbing requirements. The examination is based on the plumbing provisions contained in the applicable edition of the International Residential Code.

For the 2021 code cycle, candidates preparing for the P1 examination use the 2021 International Residential Code. The code contains requirements that apply to residential construction, including plumbing systems, fixtures, water heaters, water supply and distribution, sanitary drainage, venting, and related installation provisions.

Preparation should focus on both technical knowledge and the ability to navigate the code efficiently. Candidates may need to identify applicable code sections, interpret requirements, work with tables, apply definitions, and distinguish between similar provisions.

Because the examination is open book, familiarity with the organization of the International Residential Code is especially important. Candidates should know how to use the table of contents, index, chapter structure, definitions, tables, and section numbering to locate information efficiently.

Exam preparation is most effective when candidates repeatedly practice looking up answers in the same reference used during study. This builds familiarity with the code and helps create a consistent method for working through questions.

How does the Residential Plumbing Inspector (P1) exam work?

The Residential Plumbing Inspector (P1) exam is a code official certification. It is taken after the Virginia Building Code Academy Core class and leads to DHCD certification.

  • Virginia code officials are certified by the Department of Housing and Community Development (DHCD), not by DPOR.
  • The path is the Virginia Building Code Academy Core class, the classes for your certification, then the required exam, usually an ICC exam.
  • Building, fire and property maintenance officials apply within 12 months of hire; technical assistants have 18 months.
  • Certified officials complete 16 hours of DHCD-approved continuing education every 2 years.
