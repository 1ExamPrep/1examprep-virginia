Exam Details

The ICC B2 Commercial Building Inspector exam evaluates a candidate’s ability to inspect commercial construction using the applicable building code. The exam is based on the 2021 International Building Code for the 2021 exam version, with additional concrete-related references supporting inspection and structural concrete topics. Candidates should be prepared for multiple-choice questions that require both code knowledge and practical inspection judgment.

The ICC B2 Commercial Building Inspector exam includes 80 questions and has a 210-minute time limit. The exam is open book. Candidates should manage time carefully because many questions require locating information in the code, reading the full section, and applying the correct provision to the inspection condition described.

Major exam content areas include general administration, building planning, footings and foundations, floor construction, wall construction and coverings, roof and ceiling construction, public safety, and special construction. These topics reflect the work of a commercial building inspector, including checking construction against approved code requirements, reviewing materials and assemblies, identifying safety concerns, and recognizing when code provisions apply to a specific building condition.

The International Building Code, 2021 is the primary code reference for the exam. ACI 318-19 supports structural concrete code requirements, while the 2021 ICC Concrete Manual supports concrete quality, concrete inspection, and field practice concepts connected to the 2021 IBC and ACI 318-19.

Open Book Test

The ICC B2 Commercial Building Inspector exam is an open book test. Open book testing allows candidates to use approved reference materials during the exam, but it does not remove the need for preparation. Candidates must know how the references are organized, where key requirements are located, and how to apply code language correctly under timed conditions.

The open book format rewards candidates who practice reference navigation before exam day. Candidates should become familiar with the 2021 International Building Code table of contents, chapter organization, definitions, code tables, occupancy provisions, construction type requirements, fire-resistance provisions, means of egress requirements, structural chapters, special inspection provisions, and related commercial building requirements.

For concrete topics, candidates should study how ACI 318-19 and the 2021 ICC Concrete Manual support inspection knowledge. Concrete inspection questions may involve foundations, reinforcement, concrete quality, placement practices, field testing, structural concrete requirements, or construction documentation. Candidates should practice moving between the building code and concrete references so they can identify the correct source quickly.

Tabs, highlighting, and underlining can be helpful when they comply with current ICC testing rules. Candidates should prepare their books in an organized way and use them regularly during study. Test Information and Study Materials

The International Building Code, 2021 should be the center of the study plan for the ICC B2 Commercial Building Inspector exam. Candidates should begin by learning the layout of the code book. Reviewing the table of contents, definitions, chapter headings, and indexes helps create a roadmap for open book testing. Since the exam is timed, knowing where to look can be just as important as knowing the topic.

General administration and building planning are important study areas. Candidates should review code provisions related to permits, inspections, occupancy classification, construction type, building height and area, fire-resistance-rated construction, fire protection features, accessibility, and means of egress. These subjects often require careful reading because commercial building requirements can change based on occupancy, construction type, building size, and use.

Footings and foundations require review of soil-related provisions, foundation construction, concrete requirements, reinforcement concepts, and inspection concerns. Candidates should use ACI 318-19 and the 2021 ICC Concrete Manual to strengthen understanding of structural concrete and field inspection practices. These references help candidates connect code requirements with real inspection conditions involving concrete placement, reinforcement, quality control, and construction observation.

Floor construction, wall construction, roof and ceiling construction, and wall coverings should also be reviewed carefully. Candidates should study fire-resistance-rated assemblies, structural members, materials, opening protection, penetrations, exterior wall requirements, interior finishes, and roof assembly provisions. Commercial building inspection questions often require identifying whether a construction element matches the code requirement for the building condition described.

Public safety and special construction topics may involve safeguards during construction, special inspections, structural observation, fire protection systems, accessibility, and unique building conditions. Candidates should practice locating these provisions and reading them in context. Many exam questions depend on small details, exceptions, table notes, or defined terms.

A strong preparation routine includes timed practice with the books. Candidates should practice opening the correct reference, locating a section, reading the requirement, and applying it to the question. The goal is not to memorize every code provision. The goal is to understand the commercial inspection topics well enough to know where to look and how to apply the code accurately.

How does the Commercial Building Inspector (B2) exam work?

The Commercial Building Inspector (B2) exam is a code official certification. It is taken after the Virginia Building Code Academy Core class and leads to DHCD certification.

  • Virginia code officials are certified by the Department of Housing and Community Development (DHCD), not by DPOR.
  • The path is the Virginia Building Code Academy Core class, the classes for your certification, then the required exam, usually an ICC exam.
  • Building, fire and property maintenance officials apply within 12 months of hire; technical assistants have 18 months.
  • Certified officials complete 16 hours of DHCD-approved continuing education every 2 years.
