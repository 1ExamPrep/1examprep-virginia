### Test Information and Study Materials

A productive Virginia Journeyman Natural Gasfitter study plan should reflect the weight of the examination topics. Natural and LP Gas Piping and Pipe Sizing make up most of the technical portion, so candidates should spend significant time developing both conceptual knowledge and reference-navigation skills in these areas.

**Natural and LP Gas Piping** includes a broad range of fuel-gas system concepts. Review piping materials, fittings, joining methods, installation conditions, supports, protection, regulators, valves, appliance connections, system configuration, and related installation requirements.

When studying a piping concept, locate the corresponding material in the International Fuel Gas Code rather than relying only on summaries. This helps connect the technical idea with the language and organization of the actual reference.

**Pipe Sizing** represents 14 examination items and should receive dedicated practice. Candidates need to recognize the information provided in a sizing problem, determine which sizing method or table applies, and accurately read the applicable values.

Practice locating sizing tables repeatedly. Candidates should become familiar with how piping length, gas demand, pressure, and system conditions affect table selection and pipe-size determination. Building a repeatable process can be more useful than memorizing the answer to individual examples.

Start a sizing problem by identifying the conditions presented. Determine what information is necessary, select the applicable code table, and then verify the result carefully. Practicing this sequence can help make sizing problems more manageable under exam conditions.

**Gas Piping Controls** preparation should include regulators, valves, shutoff devices, controls, pressure-related equipment, and safety components. Candidates should know the purpose of these devices as well as the code provisions affecting where and how they are used.

**Testing** should include gas-piping pressure tests, system verification, and applicable procedures for confirming the condition of the installation. Testing questions can depend on specific code language, making careful reading and accurate reference use important.

The **Virginia regulatory material** should remain part of the weekly study schedule. Review standards of practice, standards of conduct, qualifications, definitions, renewal and reinstatement, and disciplinary provisions. These topics may be easier to locate during the exam when candidates have already worked with the regulations throughout preparation.

NFPA 58 should be reviewed when studying LP-gas concepts. Learn the organization of the standard and become familiar with sections involving containers, piping, system equipment, installation, protection, and safety. Candidates should be able to distinguish when a question is better addressed by the International Fuel Gas Code and when an LP-gas-specific reference may be more useful.

Open-book study should be active. When completing a practice question, identify the topic before opening a book. Choose the most relevant reference and locate the supporting information. If the answer is incorrect, read the surrounding code section to understand the underlying requirement rather than simply memorizing the correct choice.

Timed practice can also help candidates improve pacing. Work through groups of questions while monitoring how long it takes to answer straightforward technical questions, locate code provisions, and complete pipe-sizing problems. This can help identify reference sections that require greater familiarity.

The goal is to combine technical understanding with efficient use of the books. Candidates who know the subject and know where supporting information is located can approach open-book questions more systematically.

The Journeyman Natural Gas Fitter exam is a tradesman exam: one person is licensed, and a contracting firm in that trade also needs its own Board for Contractors license.
