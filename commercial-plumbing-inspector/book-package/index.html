Exam Details

The ICC Commercial Plumbing Inspector P2 exam is a national certification exam offered by the International Code Council. It evaluates knowledge related to commercial plumbing inspection duties and the proper application of code requirements. The exam is commonly used by inspectors, building department personnel, code officials, and construction professionals who need to demonstrate knowledge of commercial plumbing inspection.

The P2 Commercial Plumbing Inspector exam includes 60 multiple-choice questions and has a 2 1/2-hour time limit. The exam is open book and is based on the approved references for the exam. Candidates should be prepared to work directly from the reference books and answer questions by applying the correct code provisions to inspection-based scenarios.

Exam content includes general requirements, piping protection, piping installation, fixtures, water heaters, water supply and distribution, sanitary drainage, vents, traps, interceptors, separators, special piping, storage systems, and storm drainage. The exam also includes accessibility-related fixture knowledge connected to ICC A117.1-2017.

The P2 exam is not only about memorizing code sections. It measures whether a candidate can recognize the issue presented in a question, locate the correct code topic, interpret the section or table correctly, and apply it to a commercial plumbing condition. For this reason, the books in this package should be used actively during study. Candidates should practice locating requirements, working through tables, reading exceptions, understanding definitions, and moving between related code sections.

Open Book Test

The ICC Commercial Plumbing Inspector P2 exam is an open book test. Open book testing gives candidates access to approved references, but it also requires strong book navigation skills. A candidate who owns the correct books but has not practiced using them may lose valuable time searching for answers during the exam.

Successful preparation should include repeated use of the 2021 International Plumbing Code, the 2021 International Fuel Gas Code, and ICC A117.1-2017.
